# ReasonTree v1.0.0 Release Notes

Release date: 2026-04-01

---

## Initial release

This is the first public release of ReasonTree.

The core functionality is derived from the VectifyAI PageIndex open-source framework (https://github.com/VectifyAI/PageIndex), with the following additions:

- Workspace persistence for indexed documents across Python sessions.
- Support for indexing both PDF and Markdown documents through a single unified client.
- Multi-provider LLM support via LiteLLM, allowing any LiteLLM-compatible model to be used for both indexing and retrieval.
- The ability to configure separate models for indexing and retrieval.

---

## Core features

**Tree indexing for PDFs.** Build a hierarchical tree from any PDF document. If the PDF has a machine-readable table of contents, it is used directly. Otherwise, the LLM segments the content.

**Tree indexing for Markdown.** Build a tree from Markdown files using heading levels as the structure. Faster and cheaper than PDF indexing.

**Tree search retrieval.** Navigate the tree using LLM reasoning to find relevant pages. Returns page numbers, extracted text, a reasoning trail, and node IDs.

**Python API.** `ReasonTreeClient` provides `index()` and `retrieve()` as the main entry points.

**CLI.** `python -m reasontree` with `index` and `retrieve` subcommands.

---

## Limitations at v1.0.0

- No test suite.
- No Python packaging (`pyproject.toml`).
- Configuration is not validated at load time; invalid values fail silently.
- No type annotations.
- Documentation lives entirely in README.md.

These gaps are addressed in v1.1.0.
