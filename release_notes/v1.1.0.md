# ReasonTree v1.1.0 Release Notes

Release date: 2026-05-12

---

## What's in this release

This release is primarily about project infrastructure. The core indexing and retrieval logic is the same as v1.0.0, but the project now has a full test suite, proper Python packaging, validated configuration, type annotations, and documentation that lives in the repository itself rather than pointing entirely to an external site.

If you have been using v1.0.0, the main thing to know is that configuration key names have changed. See the migration notes below.

---

## New: test suite

54 unit tests cover the main components: config validation, utility functions, Markdown parsing, tree search, and the client API. All tests run without network access, using mocks for the LLM layer. You can run them with:

```bash
pytest tests/ -v
```

Coverage is at 91% overall. The uncovered lines are primarily error-handling branches that require live LLM calls to trigger.

---

## New: proper Python packaging

The project now has a `pyproject.toml`. Install it with:

```bash
pip install -e .
```

After installation, the `reasontree` command is available:

```bash
reasontree index --input document.pdf
reasontree retrieve --index results/document_tree.json --query "your question"
```

---

## New: Pydantic configuration validation

Configuration is now validated at load time using Pydantic. If you pass an invalid value, you get a clear error immediately when the config is loaded, not a confusing failure later during retrieval.

---

## Migration from v1.0.0

### Configuration key names

If you have custom `config.yaml` files or code that builds config dicts directly, the following keys have been renamed:

| Old key | New key |
|---|---|
| `toc_check_page_num` | `toc_check_pages` |
| `max_page_num_each_node` | `max_pages_per_node` |
| `max_token_num_each_node` | `max_tokens_per_node` |
| `if_add_node_id` | `add_node_id` |
| `if_add_node_summary` | `add_node_summary` |
| `if_add_doc_description` | `add_doc_description` |
| `if_add_node_text` | `add_node_text` |

Old `config.yaml` values (e.g., `"yes"` / `"no"` strings) are no longer accepted. Use `true` / `false` booleans.

### Class rename

`PageIndexClient` has been renamed to `ReasonTreeClient`. The public API methods (`index()`, `retrieve()`, `get_tree()`, `list_documents()`) are unchanged.

## Known issues in this release

- `__main__.py` (the CLI) is not covered by the unit test suite. It is tested manually but not in CI.
- Table-heavy PDFs (financial statements with dense numeric tables) occasionally produce malformed extracted text via PyPDF2, which degrades retrieval for table-specific queries. This is a known limitation of open-source PDF parsing.
- The retrieval engine is single-threaded. Sibling branch exploration is not parallelized, which means long trees with many branches take proportionally more time.
